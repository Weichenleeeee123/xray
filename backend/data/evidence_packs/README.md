# 证据包：人工采集的真实记录

公示系统、执行信息公开网等来源需要人工查询时，不绕验证码。中基协名单和公开详情页已有独立适配器，官方结果优先于手工证据包。

## 已随项目提供的公开记录

- 杭州巨鲸财富管理有限公司：浙江证监局2023年监管措施、2024年行政处罚决定中的企业事实字段。
- 杭州银行股份有限公司：2025年年度报告中的公开披露字段，保留报告期、页码和原文链接。

这两份包的公开摘录放在 `extra`，进入原始记录、版本证据与助手上下文；**不是完整工商、执行、投诉证据包**。`registry` 等没有完成核验的段不填。不能为了让某张图出现而补零、编造登记状态，或把员工人数填成参保人数。后续人工采集按 `docs/evidence-collection.md` 补充。

已人工核验的监管文书还会进入确定性信用信号：仅限服务器证据包中的 `collected/found` 记录，官方 HTTPS 域名、当事企业准确匹配、有效决定日期，以及明确的“行政处罚决定＋企业处罚结果”或“行政监管措施＋措施”字段。普通用户材料不会因此变成官方证据；来源仍标为人工采集，网址检查本身也不证明文书真实，采集人必须先核验原文。警示函与罚款分别显示，历史摘录不代表全量处罚查询或最新整改情况。报告条目数不是处罚次数，同一文书可能被多个来源收录。

## 怎么做

1. 复制 `_template.json`，改名为 `<公司全称>.json`。
2. 照着公示系统、中基协、投诉平台的页面填字段，原文照抄，不要改写。
3. 每一段的 `source` 都要写网址、采集时间，有截图就放进 `shots/`，并写上路径。
4. 没查的段整段删掉，系统会显示"没查"。查了但没有记录的，要照实填：中基协填 `"registered": false`，投诉填全 0。
5. 重启后端，在输入页输入公司全称或 `aliases` 里的简称，就会用这份证据包。

## 规则

- 只放公开、可复查的记录。不给真实公司编负面材料。
- `self_description` 放公司自己公开的说法（官网、招聘页、宣传页），系统会把它当作"宣称"去和记录对照，不当作事实。
- 宣传话术如果来自报道或判决书，写在 `note` 里，演示时界面会显示出处。
- 事后才出现的记录（比如案发后被吊销），要在 `note` 里写明日期，演示时单独说明"当时查不到"。
