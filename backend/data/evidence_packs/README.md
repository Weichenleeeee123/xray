# 证据包：人工采集的真实记录

公示系统、执行信息公开网有验证码，中基协接口本地返回 500，这些来源不写爬虫，也不绕验证码，由人工查好后存到这里。

## 怎么做

1. 复制 `_template.json`，改名为 `<公司全称>.json`。
2. 照着公示系统、中基协、投诉平台的页面填字段，原文照抄，不要改写。
3. 每一段的 `source` 都要写网址、采集时间，有截图就放进 `shots/`，并写上路径。
4. 没查的段整段删掉，系统会显示"没查"。查了但没有记录的，要照实填：中基协填 `"registered": false`，投诉填全 0。
5. 重启后端，在输入页输入公司全称或 `aliases` 里的简称，就会用这份证据包。

## 规则

- 只放公开、可复查的记录。不给真实公司编负面材料。
- `self_description` 放公司自己公开的说法（官网、招聘页、宣传页），系统会把它当作"宣称"去和记录对照，不当作事实。
- 宣传话术如果来自报道或判决书，写在 `note` 里，演示时界面会显示出处。
- 事后才出现的记录（比如案发后被吊销），要在 `note` 里写明日期，演示时单独说明"当时查不到"。
