# 案卷页统一布局（已确认，本地已接入）

本目录保留独立的布局示例。用户已确认这个方向，并要求去掉标题下“仅此浏览器可见｜跨设备暂不互通”标识。正式页面已在 `web/app.js` 的 `renderCases()` 接入，样式在 `web/cases-workspace.css`，继续复用报告页的导航和助手布局。后端接口与权限逻辑未改动。

## 设计基准

- 基于已拉取的主线 `4dd8fa6`，复用报告页的深蓝顶栏、左侧导航、暖纸色内容区及可收起的小企侧栏。
- 公司名称、查询需求、场景、版本数量、新建时间对应现有案卷列表字段。不新增未经接口支持的风险评分或“最后更新时间”。
- 示例中的三家公司均为布局占位，不是联网查询结果；页面明确标注“示例数据”。
- 已移除用户指出的标题下标识；私人案卷身份隔离保持原状，侧栏仍说明上传材料和对话不会自动公开。
- 案卷列表不冒充已经选中具体案卷；小企在打开案卷前不读取具体材料。

## 预览与边界

本轮本机预览地址：`http://127.0.0.1:8023/design-preview/cases-workspace/`。

该地址由独立的本地验收服务提供，生产服务未新增这个路由。
样式引用 `/xray/` 下现有样式，品牌素材引用 `/research-assets/`；不可只用 `file://` 打开 HTML 来判断最终效果。

只有助手收起/展开是真实的预览交互。查企、打开报告、问题按钮仅提示“布局预览”，不调用业务接口、不创建案卷、不提交材料。

正式案卷页本机入口：`http://127.0.0.1:8023/xray/#/cases`。读取现有私有 `/api/cases`，卡片打开对应报告；加载、空列表、失败重试和页面切换已接入。独立验收服务未接付费模型，使用临时数据目录，不等于公网环境。
