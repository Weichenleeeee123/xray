## 本轮发现并修复

- 模型把 JSON 字段名和值拼接成逐字引文；保留严格拒绝，并在既有最多两次内容重写预算内要求修正。
- 部分回答被剔除时遗漏关键答案；部分失败也可重写，失败时只保留曾验证通过的内容和原始来源模式。
- 日期 `09` 被改为 `9` 后未通过原有数字检查；将具体被拒数字及对应来源支持的数字反馈给模型，不放宽数字规则。
- 人工证据包原先仅进入原始数据、未进入报告；明确类别的已核验监管文书现在纳入信用信号，保留 collected 类型。条目数不当作处罚次数。
- 网点版页脚溢出第二页；仅收紧打印行距和间距，正文仍 10.5pt，辅助文字最低 9pt，不删内容。
- PDF 验收最初把上标引用的提取顺序误当漏字；改为分别核对正文和引用，保留全部内容检查。最终完整运行通过。
