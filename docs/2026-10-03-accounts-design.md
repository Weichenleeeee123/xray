# 用户系统：邮箱账号与每日限额（设计）

日期：2026-10-03，围城拍板。

## 目的

1. 换设备也能找回案卷和资料库。
2. 路演时有完整的登录、注册和找回密码流程。
3. 按账号和匿名浏览器限制每天新建研究的次数。一次真实研究要调商业接口和模型，是要花钱的。

## 决定

- 登录是可选的。不登录照现在一样能用，评委不用注册。
- 用邮箱加密码登录，忘记密码时用邮件找回，邮件通过 Resend 发送。注册时不验证邮箱，所以注册页要提示：邮箱填错就找不回密码。
- 只存邮箱和密码哈希。密码用标准库的 `hashlib.scrypt` 加随机盐，不引入新依赖。
- 限额：匿名浏览器每天 5 次，每个 IP 每天 40 次（只算匿名请求），每个账号每天 30 次。三个数都放在环境变量里（`XRAY_QUOTA_GUEST`、`XRAY_QUOTA_IP`、`XRAY_QUOTA_ACCOUNT`），设为 0 就是不限。按北京时间自然日计算。预制示例（A/B/C）的回放不计数。新建研究和补充研究都算一次。

## 身份

- 现有的匿名身份 `qier_guest` 保持不变。
- 登录成功后再发一个 `qier_user` cookie，HTTPS 下叫 `__Host-qier_user`。它是 HttpOnly、SameSite=Lax 的，有效期 180 天，内容为 `账号id.代数.签发时间.签名`。
- 中间件读到有效的 `qier_user` 时，本次请求的 owner 就是账号的 owner（`acct-<id>`），否则仍用匿名身份。
- 每次请求都会读账号文件、核对代数。改密码、找回密码、注销账号时代数加一，所有设备上的旧登录随即失效。
- 合并要用户确认。登录后，如果这个浏览器的匿名身份名下有案卷，页面会问一句是否并入账号，确认后才调用 `POST /api/auth/merge`。合并会把案卷和研究任务的 owner 改成账号。不自动合并，是怕用户在别人的电脑上登录时，把上一个人的东西吞进自己的账号。
- 退出时清掉 `qier_user`，同时换一个新的匿名身份，本地资料库的副本也一起清掉，下一个人用这台电脑看不到前一个人的东西。
- 匿名时写的评价不随合并迁移，仍挂在原来的匿名编号下。

## 存储（`XRAY_PRIVATE_DIR/accounts/`）

- `<id>.json`：`{id, email, pw, gen, created_at}`
- `by-email/<sha256(邮箱)>`：保存账号 id，用来按邮箱查账号
- `<id>.library.json`：资料库列表，最多 500 条
- 限额计数放在 `XRAY_PRIVATE_DIR/usage/<日期>.json`
- 登录失败计数和找回邮件的频率记录也放在这里，多进程共享

## 接口

| 接口 | 作用 |
| --- | --- |
| `GET /api/session` | 增加 `account`（邮箱或 null）、`quota`（今天用了几次、上限多少）和 `guest_cases`（未登录时这个浏览器名下的案卷数） |
| `POST /api/auth/register` | `{email, password}`，注册后直接登录 |
| `POST /api/auth/login` | `{email, password}` |
| `POST /api/auth/logout` | 退出登录 |
| `POST /api/auth/merge` | 把这个浏览器匿名身份下的案卷并入账号 |
| `POST /api/auth/password` | `{old, new}`，修改密码 |
| `POST /api/auth/forgot` | `{email}`，不论邮箱是否注册过都返回同一句话；邮件在后台线程发送，响应时间不暴露邮箱是否存在 |
| `POST /api/auth/reset` | `{token, password}`，用找回邮件里的令牌重设密码 |
| `POST /api/auth/delete` | `{password}`，注销账号 |
| `GET /api/me/library` | 读取资料库 |
| `PUT /api/me/library` | 写入资料库；只有登录后才能调用 |

- 找回令牌是 `账号id.签发时间.签名`，签名覆盖当前的密码哈希，所以改过密码后令牌自动作废，只能用一次。有效期 30 分钟。
- 邮件里的链接用 `XRAY_PUBLIC_URL` 拼出，不使用请求头里的 Host。
- 频率限制：同一邮箱 15 分钟内登录失败 5 次就暂时锁定；找回邮件同一邮箱 2 分钟内只发 1 封，同一 IP 每小时最多 5 封。
- IP 取 `CF-Connecting-IP`，没有就取 `X-Forwarded-For` 的第一个，再没有就取连接地址。

## 页面

- 「我的」页面顶部是账号区。没登录时显示登录/注册表单和"忘记密码"；登录后显示邮箱、今天还剩几次、改密码、退出和注销。
- `#/reset?t=…` 是重设密码页。
- 资料库：登录后打开页面时，把服务器上的列表和本地列表按词条合并，同一词条保留收藏时间较新的那份，合并结果写回两边；之后每次改动都推送到服务器。
- 达到限额时，后端返回 429 和一句中文说明，前端照常显示错误。

## 不做

手机号、第三方登录、邮箱验证、管理后台、按账号计费。

## 测试

- 后端 `tests/test_accounts.py`：注册、登录、错误密码锁定；跨客户端登录后看到同一批案卷；合并只在确认后发生；改密码后旧登录失效；找回令牌一次性且会过期；注销；限额计数（预制示例不计数）；资料库读写。Resend 用替身。
- 前端：在隔离后端里用浏览器把整个流程走一遍。
