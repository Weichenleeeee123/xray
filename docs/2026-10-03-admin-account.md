# 路演管理员账号

同一管理员账号可在三台电脑同时登录，共享名下案卷和资料库，免除每日新建研究次数限制。三台设备不会因新的登录互相下线，退出一台不影响其他设备；修改或找回密码仍会让其他设备重新登录。

管理员标记是服务器私有账号记录的 `role=admin`，只通过服务端维护授予。公开注册请求不能指定管理员权限。当前角色仅提供研究次数豁免，不提供读取其他账号数据的权限。普通账号和匿名浏览器继续沿用现有额度。

在已加载后端服务环境、特别是 `XRAY_PRIVATE_DIR` 的服务器终端，进入当前版本 `backend` 目录运行：

```sh
/opt/qier/venv/bin/python tools/admin_account.py 管理员邮箱
```

新账号通过隐藏输入设置密码；已有账号保留密码、资料和现有登录。重复运行只确认管理员身份。账号数据必须存储于持久化的私有目录，不提交到 Git。

“不限额”指应用每日研究次数。服务端并发容量、商业数据供应商额度和登录失败保护继续有效。若三台电脑需要同时启动研究，生产 `XRAY_MAX_RUNS` 至少设为 3，并确认服务器资源；仅同时登录不需要调整此项。

验证覆盖：三客户端同时保持登录、并发重复请求免额度、普通用户及匿名 IP 额度不变、注册不能提升权限、提升角色保留密码和登录、界面显示管理员及不限额。
