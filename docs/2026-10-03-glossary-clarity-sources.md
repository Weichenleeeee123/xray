# 小企术语解释修订依据

核对日期：2026-10-03。本次只修订固定词表，不更改企业风险规则，不批量重写历史案卷。

## 登记状态（沿用 `term.status`）

- 保留“存续、吊销、注销”已有别名和引用 ID。
- 去掉“存续是正常经营”的错误等同；区分主体登记状态与实际经营、盈利和业务资格。
- 司法部说明：办理歇业登记的主体可以中止经营活动，同时维持主体资格存续。因此“主体存在”不能直接推导“正常营业”。依据：[司法部关于市场主体登记制度的说明](https://www.moj.gov.cn/pub/sfbgw/zcjd/202108/t20210826_436151.html)。
- 登记与退出范围依据：[《中华人民共和国市场主体登记管理条例》第三十条、第三十一条](https://app.www.gov.cn/govdata/gov/202108/24/475109/article.html)。吊销营业执照与完成注销登记不能混同，另见[市场监管总局关于强制注销工作的说明](https://www.samr.gov.cn/xw/df/art/2026/art_d36d5d9e4d54449abfd0855f9965dbff.html)。

## 裁判文书（新增 `term.judgment_document`）

- 别名仅增加“司法裁判文书”。判决书、裁定书是种类，不作为总称的同义别名。
- 给出法院文书的用途，再说明应查看具体当事人角色、裁判结果等，不根据文书数量直接判定企业责任。
- 依据：[最高人民法院《关于人民法院在互联网公布裁判文书的规定》第三条](https://gongbao.court.gov.cn/Details/415f49dd8baaa04b479d57af9616ef.html)。其中列有判决书、裁定书及其他处理程序或实体权益的文书。
- 一般术语解释不等于对某公司的事实核验；公司事实仍需引用案卷记录。

## 股权出质、动产抵押（沿用原 ID）

- 删除“出质多可能说明缺钱”“抵押多说明靠借钱周转”的条数推断。
- 改为核对担保对象、比例或金额、期限和状态；明确抵押人可能为其他主体提供担保。
- 依据：[《中华人民共和国民法典》最高人民法院公布全文](https://www.court.gov.cn/zixun/xiangqing/233181.html)，第三百九十四条、第三百九十五条、第四百零三条、第四百四十条、第四百四十三条。
- 原来“动产抵押要去登记”的概括也予以调整：第四百零三条规定其抵押权自抵押合同生效时设立，未经登记不得对抗善意第三人；正文不再把登记概括为所有动产抵押成立的前提。

## 兼容性

- 沿用 `Term` 的 `plain`、`why`、`basis`、`law` 字段，没有新增 schema。
- 新词用 `law` 标明法规名称，不冒用企业数据来源 ID。
- 当前固定词表影响新回答和新报告解释；已保存报告的 `Version.terms` 仍保留原始内容。问答若引用更新后的词表，须随消息保存该次使用的术语快照，而非改写历史版本。
