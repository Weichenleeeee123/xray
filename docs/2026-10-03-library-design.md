# 资料库：收藏名词，回头复习（设计）

日期：2026-10-03，围城拍板。

## 目的

报告里的名词，看不懂的可以收藏起来，以后在一个单独的页面复习。只收名词解释，不收原始记录。

## 决定

- 收藏方式是手动的：在名词弹窗里点「☆ 收藏复习」，再点一下取消。不做自动汇总。
- AI 解释（`origin=model`）也可以收藏。在资料库里一直标着「AI 解释·未经人工核对」，不能因为进了资料库就像是正式资料。
- 只存在浏览器里（localStorage 的 `xray.library` 键），不改后端，不跨设备同步。这和案卷"仅此浏览器可见"的口径一致。

## 入口

- 顶栏新增第四个分区「资料库」，路由 `#/library`，放在「案卷」和「我的」之间。报告页左侧的工作空间导航跟着多出一项。
- 研究室首页菜单（`research-room/app/page.tsx`）加一个「资料库」链接。这一步要重新构建 `home-dist`，构建不了就不加。
- 所有调用 `termPop` 的地方都能收藏：报告正文、一页结论、「我的」页面的词表、小企回答里的 `名词·xx` 出处。

## 存什么

每个词存一份快照，按词条 id 去重：

```
{ id, term, plain, why, basis, origin, savedAt,
  seen: [{ caseId, version, company }] }
```

- `basis` 存的是显示用的文字：来源名称，或者法规名。
- 之所以存快照：AI 词条只在那一版报告里有，事后在词表里查不到；固定词表的措辞以后可能改，复习时看到的应该是收藏当时那一版。
- `seen` 按 caseId 去重，version 记最近一次看到的那一版。在案卷页收藏时会记下当前案卷。如果一个词已经收藏过，在另一份案卷里再打开它的弹窗，就把这份案卷追加进 `seen`。在「我的」页面收藏的词，`seen` 为空。
- 读写都包 try/catch。存不了时提示"这个浏览器存不了收藏"，页面照常能用。

## 资料库页面

- 顶部写明：共 N 个词，只存在这个浏览器里，清除浏览器数据会丢失。
- 每个词一张卡，内容依次是：词名、解释、对你意味着什么、依据或 AI 标注、「在这些报告里碰到过」（链接到 `#/case/<id>/v/<n>`），以及「移出」按钮。
- 最新收藏的排在最前。
- 没有收藏时显示：在报告里点开带虚线的词，再点「收藏复习」，就会出现在这里。

## 不做

搜索、分组、"已掌握"标记、导出、复习提醒、服务端同步。

## 测试

- `web/tests/library.test.cjs` 覆盖：存取、去重、追加 seen、取消收藏、localStorage 抛错时不崩、AI 标注、页面渲染。
- 在浏览器里实测：报告页收藏 → 资料库里出现 → 跳回报告 → 移出。
