# 后端可回退模型阶段的等待预算

需求识别默认 `XRAY_INTAKE_TIMEOUT=8` 秒，短句润色默认 `XRAY_PLAIN_TIMEOUT=12` 秒。每个阶段的首请求与 JSON 修复共享剩余预算，并尊重调用方更早的截止时间；结束后恢复上下文。配置要求有限正数。

超时使用现有关键词识别或规则模板，完整证据采集、规则判断、引用与版本保存不变。HTTPX timeout 约束传输等待并阻止超预算重试，**不是绝对墙钟时限**；此处不宣称所有网络情况下必在 8/12 秒内完成。
