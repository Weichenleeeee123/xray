# 报告阅读与查询恢复验收

工作分支：`codex/hackathon-product-polish`。原始素材、历史报告和旧发布目录均保留。

## 阅读顺序

报告首屏先呈现本次需求、当前版本、阅读摘要与下一步核实动作。摘要分为“需要核实 / 查到的记录 / 仍待确认”，每组先显示两条，其余可展开，引用不丢失。四个信号保留完整核查条目；六维轮廓折叠为可选阅读；问询与材料核对图表随后展开，完整来源仍可回看。

摘要使用当前保存版本的确定性一页结论，不重新让模型生成事实。新生成版本的概述区分异常、需留意与尚待确认；失败或未覆盖不会被概括为“没查到”，未经核实的用户评价不计入记录异常。重复、参考和不适用条目不充当信息缺口。
