# 预制报告来源与回放说明

本轮公网验收发现：精确匹配示例时，服务会把预先生成的案卷复制给当前浏览器，并回放记录的生成过程。因此不能把示例动画耗时当作实时查询性能。

现在每个预制版本保存 `prebuilt.demo_id` 与 `prebuilt.built_at`，运行流在任何回放等待之前发送来源事件。首页、经典查询进度、报告首屏和打印页均说明“本次未重新联网查询”。包时间只称“预制包生成时间”，每条来源仍保留自己的资料日期。旧案卷兼容原有“预制示例”说明，不批量改写用户历史。

预制补充只追加下一版及新增记录，历史版本和原始记录保持不变；同一原始记录编号出现不同内容会拒绝追加。真实补充、刷新与人工复核不继承“整版直接预制”的标记。人工复核说明沿用哪一版快照；缺少标记也不意味着本版一定重新联网。

验证：后端相关测试 186 项，首页测试 91 项，报告测试 86 项通过；TypeScript 和首页生产构建通过。独立审查定向测试 39 项通过。浏览器验证了隔离虚构测试包的回放、保存读回、报告、经典视图与打印预览；390×844 手机页面无横向溢出，来源提示与进度面板不重叠。

测试包和测试案卷保存在忽略目录，未替换线上预制包、未重写旧报告结论。公网发布及真实流程验证记录见性能与部署验收文档。
