# 历史版本与回答边界

报告标题旁新增版本选择器，有多版时才显示。展开后按最新到最旧列出版本、生成日期和触发原因，当前查看版本与最新保存版本分别标识。入口复用已有版本路由，不修改案卷或引用；窄屏展开后占自然文档流，避免覆盖摘要。

问答中存在被依据校验省略的表述时，显示“部分表述未获依据支持，已省略”。公开接口只增加只读布尔值 `has_omitted_claims`，条件为模型或录音回答、非 `not_found`、内部 `dropped > 0`。省略计数可能来自重写前的尝试，因此文案不声称最终回答一定不完整。无依据回答继续使用原有专门提示。

该状态由服务端计算；客户端提交同名字段不能覆盖它。内部 `dropped`、`rewrites`、`blocked` 及被拒绝文本仍不公开，内部 ChatMessage 和已保存文件没有新增字段，旧录音兼容。POST 回答、读取案卷、回复恢复与幂等重发都经过公开 DTO。

验证：新增后端测试先失败后通过，相关 59 项通过；本轮后端全量 537 项、报告 88 项通过。390×844 浏览器验证版本展开、键盘 Enter、触控按钮和 v2→v1→v2 路由，来源数随版本变化且无横向溢出。线上验证另记部署文档。
