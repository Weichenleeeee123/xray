## 本次效果

- 桌面不再常驻左上角详细进度面板。主桌电脑上方留白处显示“报告生成中”，位置为场景宽度 50%、高度 53.5%。字体相对预览 v1 放大约 28%，暖色宋体，2.8 秒明暗/光晕/缩放呼吸，省略号 1.8 秒循环。
- 已保存案卷经原接口独立读回确认后，才显示“报告已完成”：最高放大至 1.18 倍，金色光晕加强，整段 4.4 秒后淡出。角色帧更新和展开详情不会反复播放；暂停角色也不会卡住这条真实确认提示。
- 时钟仍显示真实完成百分比；社会舆情标记移至门左侧（38.8%、21%）。企鹅原有运动路径和进度调度未修改。
- 已完成且摆放结束的卷宗以 3.4 秒周期轻浮，最高 4px；悬停或键盘聚焦上浮 8px，并使用更强光晕。装订/推送卷宗时不会叠加待机浮动。
- 卷宗封面不显示日期。企业全称按主体名称与“有限公司”等后缀分行、按容器适当调字号。特别长的名称保留全部字符、可滚动，并保留完整标题及按钮无障碍名称；不把文字缩到无法辨识。
- `prefers-reduced-motion` 下不缩放闪光或持续浮动，完成提示仅缓慢淡出。

## 状态和功能边界

- 完整详细进度、每个来源结果仍在右上角详情入口及来源标记中；这次只减少常驻展示，不删数据。
- 保存未确认、保存失败、连接中断有独立提示，不能显示完成。原来的重连、重试保存、确认重新查询都保留。
- 如果后端完成但动画暂停或卷宗尚未出现，保留“报告已就绪 · 查看报告”临时入口。不能让用户等动画才能查看已保存结果。

- 后端业务和 API 契约、真实查询、完整输入恢复、案卷材料、引用/数字核对及确定性风险规则均未修改。
