# X-Ray 三分钟演示操作单

本单按 H2（`2026-10-02-xray-hackathon-prd.md`）和当前真实资料编排，供正式演示前排练。它不是验收记录或部署成功声明；学校网络、离线浏览器验证及打印效果均须另记实际结果。

## 演示前准备

- 服务与前端按 `backend/README.md` 启动；打开应用首页，确认健康状态及模型模式。`/demo/` 是旧静态演示，不是本单的主入口。
- 主线 A：杭州巨鲸财富管理有限公司。初始材料用 BOSS 历史宣传搜索摘录；补充材料用投资界机构库（pedaily，页面注明数据来自清科私募通）。两份材料均标注 2026-10-02 摘录，摘录时间不代表宣传仍有效。BOSS 末句原本截断，不补写。
- 对照 B：杭州银行股份有限公司，需求是求职，材料是历史 2022 届校园招聘转载。另有 `extra` 证据：2025 年年报（2026-04-23 披露，财务统计截至 2025-12-31）。它与旧招聘材料的时间、指标口径不同，不能直接互相证明或判成矛盾。
- A/B 均未补齐工商、执行证据。未覆盖不等于没有风险或没有执行记录；年报财务不替代工商登记，员工数不当参保人数，注册资本不当现金余额。
- 预先记下 A/B 案卷 ID、各版编号、待点的证据与引用位置。操作卡注明本场是在线模型还是“离线回放”；模板回答不称真实模型回答。

## 三分钟讲稿与点击顺序

| 时间 | 操作 | 可直接讲的话 |
| --- | --- | --- |
| 0:00–0:15 | 首页，选真实案例 A；确认公司名与需求 | “家人想把储蓄交给一家公司，我们先看它说了什么、公开记录能支持什么。” |
| 0:15–0:45 | 初始需求：`我妈想在这家公司存 20 万理财，最怕急用时取不出来`。带入 BOSS 材料，生成/打开 A 的 v1；展开“宣称 vs 记录”和一条监管原始记录 | “这是历史宣传摘录，不是今天的承诺。监管记录要看来源和日期，不能把事后记录说成当时已经知道。工商、执行未补齐的地方仍写未覆盖。” |
| 0:45–1:10 | 在监管相关判断旁点“问”，带引用提问：`这条监管记录说明了什么？还有哪些事情不能据此判断？`；也可在助手输入框直接提问并展开回答引用（原始记录弹窗本身没有“问”按钮） | “助手解释的是这条证据，不替监管部门下新结论。点引用能回到依据；离线时画面会明确写‘离线回放’。” |
| 1:10–1:40 | “＋ 补充信息”→补充材料，选准备好的 pedaily 材料；生成 v2，打开变化清单及新材料原文 | “现在加入第二份公开材料。哪些判断变了、哪些没变，要看实际变化清单；资料中的集团规模和牌照说法，不能自动算到这个收款主体身上。” |
| 1:40–2:05 | “＋ 补充信息”→“改需求”，提交：`其实我妈能拿出 120 万，想在这家公司买理财，最怕急用时取不出来`；生成 v3，看“私募门槛”及变化清单 | “从 20 万改到 120 万，改变的是用户条件，不是企业事实。若已查到私募登记，金额不足的提示可变成仍需核实合格投资者条件；120 万本身不证明合格，更不证明产品安全。” |
| 2:05–2:20 | 回到先前助手回答，点它的旧版引用；确认进入该引用所属版本，再切回最新版 | “新材料不会改写旧版依据。旧回答的引用仍回到旧版，不会误跳到新版同编号的条目。” |
| 2:20–2:35 | 打开已准备的 B 案卷，展示求职关注点和原始资料日期 | “同一方法换成求职，看的重点就不同。这里是 2022 届招聘材料；2025 年年报是另一个时间点的补充证据，不拿它为旧宣传直接背书。” |
| 2:35–2:55 | 回 A 最新版→“文字版（给家人看）”；切“给家人”与“给网点柜员”，点“打印”，打开打印预览后取消 | “一页保留依据、未查项和下一步问题。家人版便于讨论，网点版便于沟通；不是对企业的安全担保。” |
| 2:55–3:00 | 收尾 | “X-Ray 不给安全分，也不把公司定性成诈骗；把证据、缺口和该问的问题摆在一起。” |

时长由排练实测。准备好的 B 案卷和 A 各版可用于快速切换，但必须明示预先整理，不把等待过程伪装成即时完成。若未查到私募登记，不预告固定的门槛变化；按实际输出展示“事实未变、关注点如何改变”。

## 离线回放的必要条件

回放需要已有成功录制的缓存，且请求输入与录制时一致：同一案卷 ID、同一版本、同一问题文字、同一引用以及同一聊天历史上下文；模型配置和缓存命名空间也须保持一致。仅把问题文字复制一遍，但聊天历史已经改变，不保证命中。新建 UUID 案卷不能指望复用另一案卷的录制。

离线主线从快照中的固定 A 案卷 v1 打开；首页可说明初始输入，但不要重新“生成报告”建新案卷。B 对照也打开预先保存的固定案卷。

1. 联网录制前保存案卷快照，并列出准确的提问顺序、版本及引用。快照应包含录制前的聊天历史；缓存和快照留在本机，不提交仓库或发布为公共素材。
2. 联网按上述顺序录制成功响应；记录回答模式与引用，不把模板响应当录制成功。
3. 离线排练前恢复录制前案卷快照，保留对应缓存。不要先试问、改字、换引用或添加聊天，再期待原序列命中。
4. 切回放模式，并在网络阻断条件下由浏览器按原顺序验证。离线展示既有公开证据，不称正在实时联网查询；引用跳到本地原始证据，外部来源链接断网时可能打不开。
5. 缓存未命中或动作失败时展示实际提示，停止该步骤或明确切到已有版本。不可临时换一个新案卷假装回放成功；恢复网络后的在线重试须重新说明模式。

网络阻断浏览器验证、快照恢复与现场手动排练由后续实际执行记录补充；本单不预先认定这些检查已经通过。
