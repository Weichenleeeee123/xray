# 研究室正式首页接入

队友最新代码 `61109a4` 已拉取。正式首页直接复用 `research-room/app/page.tsx`、动作控制器和桌面卷宗，不复制成另一份动画页面。

## 运行与页面地址

1. 在 `research-room` 执行 `npm install`、`npm run build:home`。构建到被 Git 忽略的 `home-dist/`，不会清空已有目录或删除旧产物。
2. 在 `backend` 执行 `.venv/Scripts/python -m uvicorn app.main:app --port 8000`。
3. 打开 `http://localhost:8000`。无需常驻 Node 前端服务。

| 地址 | 用途 |
|---|---|
| `/` | 新研究室首页 |
| `/?run=<编号>` | 恢复同一次后台查询 |
| `/xray/#/cases` | 案卷列表 |
| `/xray/#/case/<id>` | 报告与问答 |
| `/xray/#/case/<id>/v/<n>` | 历史版本 |
| `/xray/#/me` | 状态和说明 |
| `/xray/#/new` | 附带材料的完整查询表单与演示案例 |
| `/research-assets/` | 研究室场景、角色和卷宗图片 |
| `/office/assets/` | 编译后的首页脚本与样式 |
| `/demo/` | 原静态备用演示 |

旧的 `/#/case/...`、`/#/cases`、`/#/me` 书签由新首页转到 `/xray/`，保留查询参数和报告版本。报告壳的首页品牌、查企导航返回 `/`。

按用户最新选择，入口和样式恢复为队友 `61109a4` 原版：公司全称、开始查询按钮和下方直接显示的“研究需求（选填）”。不使用一句话拆解或折叠需求的新方案。留空时默认了解公司的登记、资质与公开资料；填写时原样作为 need 传给真实任务接口。右下角菜单保留案卷、材料表单和说明入口。

房间布局及响应式样式沿用队友原版，静态资源同源挂载、真实任务恢复、保存确认和报告导航继续使用已完成的接入。

## 真实任务驱动的动作

| 后端步骤 | 房间位置或动作 |
|---|---|
| `intake` | 桌前读懂需求 |
| `lists`、`registry` | 企业资料柜 |
| `amac`、`finance` | 经营数据终端 |
| `pack` | 图书资料区 |
| `web` | 政府公告栏 |
| `opinion`、`reviews` | 门口听取新闻、投诉和评价；确有记录才出现访客 |
| 全部查询步骤结束 | 收纸、整理、回到座位 |
| `rules` | 桌前对照记录与规则 |
| `plain` | 桌前撰写报告 |
| 后端完成且案卷读回校验通过 | 装订、推送卷宗，允许打开真实报告 |

没有真实查询事件，鹅不会自行出发。查询尚未结束时留在对应资料点；标为“未查询”的步骤不演成查到。正在执行的资料任务优先于已结束的动作积压。脚步和装订需要自然的动作时间，后台如果先完成，用户可以直接打开报告，不必等待动画播完。

断线或后端报错时冻结动作并显示真实状态；暂停按钮只影响动画。资料数量来自后端事件，不使用定时百分比或编造记录数。

## 请求链路

`POST /api/runs` → 把 run 编号存到地址栏 → `GET /api/runs/{id}?after=<游标>` → 收到完成状态 → `GET /api/cases/{id}` 校验保存 → 同标签进入报告。

创建请求带独立的 Idempotency-Key 和取消信号；连接恢复只读原任务，不重新创建。保存校验失败时只重试读取案卷。明确选择“重新查询”才会创建新任务。

独立 Vinext 预览仍可使用：其 `/api`、`/xray/`、`/research-assets/` 都指向最新后端。正式使用以同源 FastAPI 入口为准，旧后端进程需要重启才能加载新接口和挂载。

## 验证

Node 回归覆盖动作阶段、真实事件结果、任务恢复、保存确认、卷宗装订，以及原报告的版本问答。后端集成测试覆盖根首页、报告壳、构建资源、图片、真实任务创建与恢复。

浏览器验收使用隔离数据目录、关闭外部收费数据服务的后端：通过真实 HTTP 创建虚构公司的案卷，确认任务编号、11 个步骤的 start/done 事件、保存案卷、刷新恢复及报告导航。虚构案例数据不等于合成动画事件。

2026-10-02 验收结果：53 项 Node 测试、16 项后端挂载/进度/任务测试通过，TypeScript 检查和 `build:home` 通过。桌面、390px 与 320px 竖屏均已检查；已验证材料表单入口、任务详情展开/关闭、报告 → 案卷 → 首页往返、旧报告书签跳转。多次刷新恢复后，隔离案卷目录仍只有首次创建的同一份案卷。
