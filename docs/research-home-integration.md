## 运行与页面地址

1. 在 `research-room` 执行 `npm install`、`npm run build:home`。构建到被 Git 忽略的 `home-dist/`，不会清空已有目录或删除旧产物。
2. 在 `backend` 执行 `.venv/Scripts/python -m uvicorn app.main:app --port 8000`。
3. 打开 `http://localhost:8000`。无需常驻 Node 前端服务。

| 地址 | 用途 |
|---|---|
| `/` | 新研究室首页 |
| `/?run=<编号>` | 恢复同一次后台查询 |
| `/xray/#/cases` | 案卷列表 |
| `/xray/#/case/<id>` | 报告与问答 |
| `/xray/#/case/<id>/v/<n>` | 历史版本 |
| `/xray/#/me` | 状态和说明 |
| `/xray/#/new` | 附带材料的完整查询表单与演示案例 |
| `/research-assets/` | 研究室场景、角色和卷宗图片 |
| `/office/assets/` | 编译后的首页脚本与样式 |
| `/demo/` | 原静态备用演示 |

旧的 `/#/case/...`、`/#/cases`、`/#/me` 书签由新首页转到 `/xray/`，保留查询参数和报告版本。报告壳的首页品牌、查企导航返回 `/`。

按用户最新确认，首屏保留公司名和研究需求两个输入框，不增加“替谁判断”和金额入口。需求选填，留空时了解公司的登记、资质与公开资料；附带材料可从右下角菜单进入完整表单。资料标签在查询启动后出现。桌面公司的全称显示在主桌电脑内，时钟显示真实环节完成百分比，案卷读回校验通过后才到 100%。

首页入口沿用队友原版。查询时展示当前后端任务及“理解需求、查询资料、整理分析、生成报告、保存报告”阶段总览；窄屏把进度面板放到房间下方，避免遮住资料点。静态资源同源挂载、真实任务恢复、保存确认和报告导航继续使用已完成的接入。

需求栏下的“试试示例”从 `/api/demo/cases` 读取可用案例。点击只填入公司、需求和初始材料，再点击“开始查询”才提交 `/api/runs`；材料可展开查看或取消选用，虚构案例标注“虚构”。更换公司会清除示例附带内容，修改需求会清除预设场景、金额和对象，但保留该公司的材料。失败后重新发起保留原材料；报告页继续提供后续补充示例。

## 真实任务驱动的动作

| 后端步骤 | 房间位置或动作 |
|---|---|
| `intake` | 桌前读懂需求 |
| `lists`、`registry` | 企业资料柜 |
| `amac`、`finance` | 经营数据终端 |
| `pack` | 图书资料区 |
| `web` | 政府公告栏 |
| `opinion`、`reviews` | 门口听取新闻、投诉和评价；确有记录才出现访客 |
| 全部查询步骤结束 | 结束当前移动，跳过过时的查阅动作，返回座位归档 |
| `rules` | 桌前对照记录与规则 |
| `plain` | 桌前撰写报告 |
| 后端完成且案卷读回校验通过 | 装订、推送卷宗，允许打开真实报告 |

没有真实查询事件，鹅不会自行出发。只访问仍在执行的资料任务，不补播已结束的资料点。行走速度由每秒 145 提高到 560 场景像素；收集结束后沿合法路线返回，不瞬移、不穿桌。后台如果先完成，用户可以直接打开报告，不必等待短暂的归档与装订动画。

资料点将进度与结果分开：等待、查询中、已完成、已跳过、部分失败、状态待确认。完成表示查询结束，不表示每项都有记录；点击资料点可查看对应子任务及查到、未找到、未查询、失败的结果。断线后的查询不会继续高亮为进行中。

断线或后端报错时冻结动作并显示真实状态；暂停按钮只影响动画。资料数量来自后端事件，不使用定时百分比或编造记录数。

## 请求链路

`POST /api/runs` → 把 run 编号存到地址栏 → `GET /api/runs/{id}?after=<游标>` → 收到完成状态 → `GET /api/cases/{id}` 校验保存 → 同标签进入报告。

创建请求带独立的 Idempotency-Key 和取消信号；连接恢复只读原任务，不重新创建。保存校验失败时只重试读取案卷。明确选择“重新查询”才会创建新任务。

独立 Vinext 预览仍可使用：其 `/api`、`/xray/`、`/research-assets/` 都指向最新后端。正式使用以同源 FastAPI 入口为准，旧后端进程需要重启才能加载新接口和挂载。
