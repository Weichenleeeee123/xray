# 研究室单输入框调整

**目标：** 按用户已确认的方向，研究室直接作为单一输入框的背景；没有开始屏、按任意键或额外进入步骤。

**实现：** 复用现有 React 表单和 `begin(company)` 接口，省略需求时采用已有默认研究需求。仅修改 `research-room/app/page.tsx` 与 `globals.css`。首屏隐藏资料标签、品牌叠层，标题、需求栏和说明从入口移除；次要链接收进原生 details 菜单。查询后的任务、报告和错误处理保持原流程。

- [x] 页面：一个带无障碍标签的公司输入框和回车图标提交按钮；校验至少两个有效字符；中文输入法确认候选词时不提交。
- [x] 样式：桌面和手机均叠在房间内，半透明深色底、暖色文字；按钮可触摸，键盘焦点可见；手机查询中的任务布局保留。
- [x] 验证：构建、TypeScript 和 53 项 Node 测试通过；浏览器已检查 1280px/390px 首屏、角落菜单、过短输入拦截及测试事件模式的 Enter 提交。手机无横向溢出，输入框位于房间边界内。

不删除文件，不改后端，不自动提交或推送本轮调整。此为小范围可逆界面调整，使用浏览器验收，不新增仅复述 DOM 的测试。
