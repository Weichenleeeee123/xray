# 企er产品路演构建说明

本目录包含可编辑 PPTX、讲稿、三分钟压缩稿、答辩稿与构建源码。PPTX 使用 `@oai/artifact-tool` JavaScript ES modules 制作。关键文字是可编辑文本，查询状态与能力边界是原生表格，产品截图与品牌插画保留为图片。

当前审查版为 `企er-产品路演-5分钟-v04.pptx`，共 12 页（10 页主讲、2 页答辩附录）。主讲分配 300 秒；`预览-v04.webp` 提供整套页面概览。

## 内容

- `企er-产品路演-5分钟-vXX.pptx`：带版本号的导出文件。保留旧版本，不覆盖。
- `逐页讲稿-5分钟.md`：与幻灯片 speaker notes 一致的主讲正文、停留提示和来源口径。
- `三分钟压缩稿.md`：同一套十页的短版讲稿。
- `答辩问题与回答.md`：按当前实现与能力边界整理。
- `build-deck.mjs`：可复现构建源代码。
- `assets/`：原有插画和产品截图。旧图保留，更新图使用新文件名。

## 复现

从仓库根目录执行。使用 Codex 已有的 bundled runtime，不安装替代运行时。先把源文件复制到私有构建目录，使 bare import 能找到 bundled packages。使用一个尚不存在的版本号，例如 `v20`，因为校验器不会覆盖已有 PPTX。

```powershell
New-Item -ItemType Directory -Path '.tmp/pitch-product' -Force | Out-Null
if (-not (Test-Path -LiteralPath '.tmp/pitch-product/node_modules')) {
  New-Item -ItemType Junction -Path '.tmp/pitch-product/node_modules' -Target 'C:\Users\Weichen Li\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules' | Out-Null
}
Copy-Item -LiteralPath 'output/pitch-product/build-deck.mjs' -Destination '.tmp/pitch-product/build-deck.mjs'
& 'C:\Users\Weichen Li\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' '.tmp/pitch-product/build-deck.mjs' v20
```

源代码顶部列出当前机器的 bundled runtime 与 Presentations 技能绝对路径。更换机器时，先通过 `load_workspace_dependencies` 获取新的真实路径，再更新这些配置。不要把缺少运行时当作安装其他工具的理由。

构建会导出私有草稿，执行结构、尺寸、字体、标题与原生表格检查，另存最终 PPTX，再导入最终文件并渲染所有页面。验证文件与逐页 PNG 位于 `.tmp/pitch-product/<版本号>/`。

当前 bundled `artifact-tool` 未按给定 crop 参数导出截图裁剪区域。构建因此在其原始导出之后，使用 JSZip 仅写入对应图片的原生 PowerPoint `a:srcRect`，保留原图和所有可编辑对象，再执行完整校验与重新导入渲染。原始导出、裁剪记录和校验后的版本均保存在私有构建目录。截图裁剪只是聚焦产品区域，没有重画界面或改写画面内容。

修改后仍须逐页查看渲染图。自动检查不能证明事实准确，也不能代替目标演示设备上的字体与投影检查。此项目没有使用 PowerPoint 桌面端或 LibreOffice 执行最终原生应用验收。
